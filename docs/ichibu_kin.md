# 一分金（江戸時代の金貨・一分金（1両の4分の1））台本と出典

- 尺: 74.8 秒
- 作られた地域: （貨幣の解説のため産地はなし）
- 現在の所蔵: （特定の実物を扱わないため所蔵先はなし）
- 時代: 江戸時代。慶長一分金から万延一分金まで、改鋳ごとの一分金が図録に並ぶ（出典E43・E44）。発行開始年は確認できた公式資料に記載なし

## 伝承として扱う点（断定しない）

- 一分金の発行開始年・品位・重さ（実数）・形・寸法は、確認できた公式資料に記載がないため台本では言わない。映像の形・刻印はイメージ
- 「小判と常に同時に発行され、重さも金の含有量も正確に4：1」は出典E43の図録本文。抽出テキストでは「小判（1両）と一分金（1/4両）とは」に続く文として読める
- 「約9割減った」は小判（慶長→万延）についての記述（出典E43）。一分金について直接言ったものではないので字幕に「小判は」と明記する
- 1分＝1625文は出典Bの公定相場（1両＝6,500文）を4で割ったこちらの計算。そば約100杯は1625÷16（そば1杯16文、出典B）のこちらの計算
- 「約2万円」は出典Bの仮の計算（18世紀の米価で1両＝約81,000円）を4で割ったこちらの計算
- 時代劇で一分金がどう使われていたか、庶民が使ったかどうかは公式資料に記載がないため言わない

## 3Dモデルの寸法

- 角の丸い長方形の金貨（表に一分の文字）を想定したイメージ。形・大きさ・刻印は一般的な形を参考にした推定で、特定の一分金や出典の記載に基づくものではない。画面上は大きさをそろえるため拡大して表示。
