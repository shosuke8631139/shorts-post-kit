# 水龍剣（直刀 無銘（号水龍剣） 附梨地水龍瑞雲文宝剣）台本と出典

- 尺: 33.2 秒
- 作られた地域: 記載なし（出典A）。刀身は無銘
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 刀身 奈良時代・8世紀、拵 明治6年（1873）（出典A）

## 伝承として扱う点（断定しない）

- 奈良時代の直刀は正倉院宝物を除けば数は少ない（出典A）
- 切刃造で重ねが厚く、僅かに刃方へ反った内反り。細直刃。茎先に大きな孔を一つ（出典A）
- 聖武天皇の御剣として正倉院に伝来、明治5年（1872）に明治天皇の元に取り寄せられた（出典A）
- 翌6年に加納夏雄による水龍文の拵が製作され、水龍剣と称されるようになった（出典A）
- 拵は映像に描かない（刀身のみ）
