# 北条太刀（三鱗文兵庫鎖太刀（号北条太刀）（中身 太刀 無銘伝一文字））台本と出典

- 尺: 39.0 秒
- 作られた地域: 備前国（岡山県）一文字派の作と考えられる（出典A「〜と考えられる」）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 明治20年（1887）、静岡県の三島神社（現三嶋大社）から明治天皇が取り寄せた（出典A）
- 拵の鞘と柄の俵鋲に三鱗紋があることから北条家奉納と伝えられ、北条太刀と号される（出典A「〜と伝えられた」）→ 台本も「伝えられ」
- 兵庫鎖太刀は帯取に兵具用の鎖を用いた太刀。社寺への奉納にも用いられた（出典A）
- 刀身は鎬造・丸棟・腰反り高く、カマス鋒。小模様の丁子刃で足・葉が盛んに入る（出典A）
- 無銘だが備前国一文字派の作と考えられる（出典A「〜と考えられる」）→ 台本も「考えられています」
- 映像は刀身のみ。拵（三鱗紋の金具・兵庫鎖）は描いていない
