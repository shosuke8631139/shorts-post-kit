# 雲生（太刀 銘雲生）台本と出典

- 尺: 37.6 秒
- 作られた地域: 備前国宇甘郷（岡山県）。雲生は宇甘郷に住した鎌倉時代末期の刀工（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 刀身は鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 雲生・雲重・雲次と続いたことから、一派は「雲類」とも呼ばれている（出典A）
- 作風は同国の長船派よりも、隣国備中の青江派に通じる（出典A）
- 中反りのついた長大な太刀姿は製作当初のままで貴重（出典A）
- 小板目肌が詰み黒みを帯びた映り、匂口の締まった直刃（出典A）
- 物打に刃こぼれがあり、実際に用いられたことが分かる（出典A）
- 拵（江戸時代・19世紀）は映像では描いていない
