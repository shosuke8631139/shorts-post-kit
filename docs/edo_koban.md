# 小判（江戸時代の金貨・小判（1枚＝1両））台本と出典

- 尺: 66.7 秒
- 作られた地域: （貨幣の解説のため産地はなし）
- 現在の所蔵: （特定の実物を扱わないため所蔵先はなし）
- 時代: 1601年に慶長金銀を発行（出典C）。江戸時代の260年の間に、金の品位が異なる10種類の小判が発行された（出典B）

## 伝承として扱う点（断定しない）

- 1両の現在価値は出典Bでも「答え：簡単には言えません」。台本の金額は出典Bが示す「仮に〜で計算すると」の例（米価で81,000円、大工の賃金で414,000円）をそのまま「約8万円」「約41万円」と言い、どちらかを正解と断定しない
- 出典A（FAQ一覧）とFAQの回答ページ（answer.html）で数値が違う（米価 約8万円／約6万円、大工 約41万円／約35万円）。計算の根拠（2024年の統計）が明記されている出典Bの数値を使う
- そば（1両＝約406杯）の例は公定相場1両＝6,500文が前提で、幕末の実勢は8,000文を上回る（出典B）ため、尺の都合もあり台本では使わない
- 金の量（慶長小判 約15g、万延小判 約2g）は出典Bの「重さ×品位」の計算。小判は計数貨幣で、金の量で価値が決められていたわけではない（出典B）ので、「金の量＝値打ち」とは言わない
- 茣蓙目（ござめ）・刻印など小判の見た目は今回確認できた公式資料に記述がないため、台本では言わない（映像はイメージ）
- 金の換算（ナレーション）は出典Bの「仮に金1g 約12,000円とすると、慶長小判には約15gの金が含まれ180,000円」に倣った仮の計算。万延小判（約2g）の約2万4千円は同じ条件でこちらが計算した値。小判の値打ちは金の量で決まっていたわけではない（出典B）ので、その注意も台本で言う。実際の金の値段は日々変わる
