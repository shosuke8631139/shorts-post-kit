# 福島兼光（太刀 銘備州長船住兼光 観応□年八月日（名物福島兼光））台本と出典

- 尺: 39.4 秒
- 作られた地域: 備前国（岡山県）。作者兼光は備前国長船派の棟梁（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 南北朝時代・14世紀（出典A）

## 伝承として扱う点（断定しない）

- 福島正則が広島の本覚寺から手に入れたためこの名がある（出典A）
- 兼光は景光の子と伝え（出典A「〜と伝え」）→ 台本も「伝わり」
- 南北朝時代に多い大振りで豪壮な太刀。直刃調に逆がかった小丁子刃の交じった刃文（出典A）
- 年紀「観応□年」の□は欠字のため、映像の茎には表の銘のみ描く
