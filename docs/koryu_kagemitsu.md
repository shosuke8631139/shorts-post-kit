# 小龍景光（太刀 銘備前国長船住景光 元亨二年五月日（号小龍景光））台本と出典

- 尺: 39.6 秒
- 作られた地域: 備前国（岡山県東南部）。作者景光は長船派三代目（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・元亨2年（1322）（出典A）

## 伝承として扱う点（断定しない）

- 表の樋の中に倶利伽羅龍、裏に梵字を浮彫。刀身の元から龍がのぞいているように見えるので「のぞき龍景光」ともいわれた（出典A）
- 幕末に山田浅右衛門家の所有となり、明治天皇に献上（出典A）
- 景光は光忠に始まる長船派の三代目。父長光と比べ華やかさは異なるが地鉄の冴えが優れる（出典A）
- 裏の梵字は形の資料がないため映像に描かない
