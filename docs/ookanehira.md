# 大包平（太刀 銘備前国包平作（名物大包平））台本と出典

- 尺: 37.2 秒
- 作られた地域: 備前国（岡山県東南部）。古備前の刀工・包平（出典A）
- 現在の所蔵: 東京国立博物館（出典A・B）
- 時代: 平安時代・12世紀（出典A）

## 伝承として扱う点（断定しない）

- 「我が国第一の名刀ともいわれる」（出典B）、「日本刀の中でも最高傑作の一つとして名高い」（出典A）→ どちらも評価の言葉なので「〜ともいわれる」「〜として名高い」のまま
- 名物「大包平」の名は『享保名物帳』に記載（出典A）。名前の由来（大きいから）は出典が明言していないので断定しない
- 反りは出典Aが3.5、出典Bが3.4 → 数値は台本で言わない
