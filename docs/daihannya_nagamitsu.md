# 大般若長光（太刀 銘長光（号大般若長光））台本と出典

- 尺: 35.6 秒
- 作られた地域: 備前国長船（岡山県東南部）。作者長光が長船派の刀工（出典A・B）
- 現在の所蔵: 東京国立博物館（出典A・C）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 足利将軍家に伝わったことは「伝えられたといい」（出典A）→ 台本では「伝わったといい」と伝聞のまま
- 600貫と大般若経600巻の結び付けは、号の由来として出典A・B・Cが一致して記載
- 信長→家康（姉川合戦の功）→奥平信昌（長篠合戦の功）は出典Aの記載。合戦の功の部分は台本で「〜の功で」と出典どおり
