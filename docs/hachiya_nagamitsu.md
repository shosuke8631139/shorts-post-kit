# 蜂屋長光（小太刀 銘長光（名物蜂屋長光））台本と出典

- 尺: 39.1 秒
- 作られた地域: 備前国（岡山県）。作者長光は備前国長船派の刀工（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 号の由来＝豊臣秀吉のころ、蜂屋という「あふれ者」が所持していたこと。『享保名物帳』による（出典A「〜とされている」）→ 台本も「とされます」
- 小太刀は寸法の短い太刀で、用途は明白ではない（出典A）
- 長光は文永11年（1274）から約30年活躍。互の目丁子刃で足がよく入り華やか、長光の典型的な作風（出典A）
