# 直行（脇差 銘 薩州住直行）台本と出典

- 尺: 36.2 秒
- 作られた地域: 銘に「薩州住」。博物館は「薩摩有縁の刀工とみて差し支えない」と記載（推定の表現なので台本では「〜とみられています」）
- 現在の所蔵: 九州国立博物館（ColBase「所蔵者」欄。飯田慶雄氏寄贈）
- 時代: 江戸時代 18世紀（ColBase の時代欄）。解説には「江戸時代後期以降」ともあるので、台本では「江戸時代」までにとどめる

## 伝承として扱う点（断定しない）

- 村正との関係は「あたかも村正系統にあるような」茎の形の比喩。村正と関係があるとは書かれていない → 博物館の言葉として引用し、関係を断定しない

## 3Dモデルの寸法

- 刃長32.2cm・反りなし・平造・庵棟は出典A。鵜の首造・重ねが極めて厚い・たなご腹の茎・目釘孔1・刃文（直に焼き出し湾れる）・銘の位置（指表の棟寄り「薩州住平直行」）は出典Aの解説。元幅・先幅・重ねの数値・茎長は記載がないため推定。鵜の首造の細部の形は再現していない（イメージ）。画面上は大きさをそろえるため拡大して表示。
