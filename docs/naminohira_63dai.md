# 波平行安（太刀 銘 正国六十三代孫波平住大和介平行安 安政六年正月日 附菊紋散糸巻太刀拵）台本と出典

- 尺: 39.0 秒
- 作られた地域: 銘に「波平住」とある（波平＝薩摩国、現在の鹿児島市の南郊。出典C）
- 現在の所蔵: 東京国立博物館（ColBase「所蔵者」欄）
- 時代: 銘に「安政六年正月日」（安政6年＝1859年）

## 伝承として扱う点（断定しない）

- 「正国六十三代孫」は銘に刻まれた名乗り。系譜が史実として何代目かを検証した資料ではないので、「〜と刻まれている」「〜と名乗っている」と表現する
- 正国が大和から出たという話は出典Cで「所伝」 → 台本では扱わない
