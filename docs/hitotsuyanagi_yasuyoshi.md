# 一柳安吉（短刀 銘左安吉（名物一柳安吉））台本と出典

- 尺: 39.7 秒
- 作られた地域: 記載なし。作者の左安吉は、筑前国の刀工・左文字の子と伝えられる（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 南北朝時代・14世紀（出典A）

## 伝承として扱う点（断定しない）

- 左安吉は、銘に「左」と記す筑前国の刀工・左文字の子と伝えられる（出典A「〜と伝えられる」）→ 台本も「伝えられます」
- 正平12年（1357）・同17年（1362）の銘の作品があり、南朝の年号であることから南朝の勢力圏にいたと考えられる（出典A「〜と考えられる」）→ 台本も「考えられています」
- 作風は小沸のついた小互の目刃が目立つ（出典A）
- 『享保名物帳』所載。美濃国の武将・一柳直盛が所持したことからこの名があり、後に前田家に伝来（出典A）
