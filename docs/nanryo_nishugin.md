# 南鐐二朱銀（江戸時代の銀貨・明和南鐐二朱銀（8枚＝小判1両））台本と出典

- 尺: 79.0 秒
- 作られた地域: （貨幣の解説のため産地はなし）
- 現在の所蔵: （特定の実物を扱わないため所蔵先はなし）
- 時代: 1772年、江戸幕府が金貨単位の計数貨幣として発行（出典C）

## 伝承として扱う点（断定しない）

- 「南鐐」の意味、品位（純度）、田沼意次の関与、形・寸法・重さは、今回確認できた公式資料に記載がないため台本では言わない
- 表面の文言は出典Cの「8枚で小判1両に換える」という説明に基づく。映像の刻印（以南鐐八片換小判一両）・形・模様はイメージ
- 「2朱×8枚＝16朱＝1両」は出典Aの1両＝4分＝16朱からのこちらの計算
- 1765年の明和五匁銀の話（12枚＝1両に固定しようとして両替商が反発）は出典C。「失敗した」とは言わず「強く反発した」と言う
- 「約1万円」は出典Bの仮の計算（18世紀の米価で1両＝約81,000円）を8で割ったこちらの計算

## 3Dモデルの寸法

- 角の丸い長方形の銀貨（表に「以南鐐八片換小判一両」の文字）を想定したイメージ。形・大きさ・刻印は一般的な形を参考にした推定で、出典の記載に基づくのは「8枚で小判1両に換える」という文言の内容のみ。画面上は大きさをそろえるため拡大して表示。
