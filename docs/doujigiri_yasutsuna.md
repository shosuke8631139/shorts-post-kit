# 童子切安綱（太刀 銘安綱（名物童子切安綱））台本と出典

- 尺: 39.3 秒
- 作られた地域: 伯耆国（鳥取県西部）。作者安綱が伯耆国の刀鍛冶（出典A）
- 現在の所蔵: 東京国立博物館（出典A・B）
- 時代: 平安時代・10～12世紀（出典A）

## 伝承として扱う点（断定しない）

- 源頼光が大江山で酒呑童子を斬った太刀という話は『享保名物帳』が記す「伝説」（出典A）→ 台本では「〜と記しています」「伝説」と明示し、史実として断定しない
- 酒呑童子伝説は室町時代に生まれたと「考えられている」（出典A）→ 同じく推定の表現のまま使う
- 「天下五剣」は「古来〜といわれた」（出典A）→ 「といわれてきました」
