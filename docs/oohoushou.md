# 大保昌（短刀 銘□都高市郡住藤原貞吉 文保元丁巳年二月吉日（号大保昌））台本と出典

- 尺: 37.8 秒
- 作られた地域: 大和国（奈良県）。保昌派は高市郡に居住した刀工（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・文保元年（1317）（出典A）

## 伝承として扱う点（断定しない）

- 保昌派には貞吉・貞宗・貞清などがいる。柾目肌の地鉄に沸がよくついた直刃が特色（出典A）
- 平造りで大振り、重ねが厚い（出典A）
- 名物桑山保昌と並んで貞吉の代表作とされる（出典A）
- 江戸時代には加賀藩の前田家に伝来（出典A）
- 銘に欠字（□）があるため、映像の茎には銘を描かない
