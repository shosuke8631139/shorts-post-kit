# 鳴狐（刀 銘左兵衛尉藤原国吉（号鳴狐））台本と出典

- 尺: 39.3 秒
- 作られた地域: 山城国（京都府）。作者国吉は山城国の粟田口派（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 平造の短刀を大きくして反りをつけたような姿で、鎌倉時代に打刀と称していたものと思われる（出典A「〜と思われる」）→ 台本も「考えられ」
- 鎌倉時代の作品としては珍しい（出典A）
- 国吉は則国の子と伝え、銘から藤原氏で左兵衛尉を称していたことが知られる（出典A）
- 小沸出来の直刃（出典A）
- 鳴狐の号の由来は明らかではないが、出羽国山形藩の秋元家に伝来（出典A）
