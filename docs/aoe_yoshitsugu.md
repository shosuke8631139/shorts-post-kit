# 青江吉次（太刀 銘備中国青江住右衛門尉平吉次 元徳二年五月日）台本と出典

- 尺: 38.2 秒
- 作られた地域: 備中国（岡山県西部）。青江派の吉次（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 元徳2年（1330）（出典A。時代区分は出典の表記に従い台本では年のみを述べる）

## 伝承として扱う点（断定しない）

- 備中国では鎌倉時代に青江派が興る。鎌倉時代末期の青江派を中青江と呼び、この太刀は中青江の吉次の作（出典A）
- 中青江の作品には、この太刀のように銘に製作年・製作地・官名をきったものが多く見られる（出典A）
- 板目肌が細かく肌立ち、青江派独特の縮緬肌の地鉄。映りが全体に立つ（出典A）
- 刃文は高低差の少ない小丁子刃で、匂口は締まりごころ（出典A）
- 明治時代に毛利家より明治天皇へ献上（出典A）
- 映像の茎には表の銘のみを描き、裏の年紀は描いていない
