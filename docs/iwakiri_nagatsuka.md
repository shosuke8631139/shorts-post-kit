# 岩切長束藤四郎（短刀 銘吉光（名物岩切長束藤四郎））台本と出典

- 尺: 34.9 秒
- 作られた地域: 山城国（京都府）。作者吉光は山城国・粟田口派の刀工（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 古来より短刀の名手として名高く、相州正宗、郷義弘と並んで三作と称される（出典A）
- 「岩切」の由来は不明（出典A）
- 豊臣秀吉から長束正家が拝領し、福島正則に移り、後に奥平家の所有となった（出典A）
- 吉光としては小振り。小板目の地鉄に小沸出来の直刃（出典A）
- 読みは出典Aの表記「いわきりながつかとうしろう」に合わせ、長束は「ながつか」と読む
