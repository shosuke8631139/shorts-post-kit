# 信州打刃物（信州打刃物（経済産業大臣指定 伝統的工芸品））台本と出典

- 尺: 39.2 秒
- 作られた地域: 長野県 上水内郡信濃町、飯綱町 他（出典B）
- 現在の所蔵: （工芸品の産地紹介のため所蔵先はなし）
- 時代: 16世紀後半・川中島合戦当時の職人から技術を習得したのが始まり「と言われる」（出典A）。指定は昭和57年＝1982年3月5日（出典A・B）

## 伝承として扱う点（断定しない）

- 起源（川中島合戦当時の職人から里の人々が鍛冶を習得）は出典Aで「と言われる」→ 台本も「といわれます」
- 「芝付け」「つり」は19世紀前半の考案で現在の信州鎌の原型（出典A）。鎌の話なので包丁の特徴としては言わない
- 値段そのものは公式資料にないので扱わない

## 3Dモデルの寸法

- 三徳型の包丁（刃渡り18cm・八角の木柄・黒い口輪）を想定したイメージ。本来の三徳は両刃が多いが、ここでは片刃の形で表現している。寸法・形は一般的な形を参考にした推定で、特定の製品や出典の記載に基づくものではない。画面上は大きさをそろえるため拡大して表示。
