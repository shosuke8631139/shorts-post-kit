# 上杉太刀（群鳥文兵庫鎖太刀（号上杉太刀）（中身 太刀銘一））台本と出典

- 尺: 38.9 秒
- 作られた地域: 備前国（岡山県東南部）。刀身は福岡一文字派の太刀（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 兵庫鎖太刀は帯取に兵具用の鎖を用いた太刀。のちに社寺への奉納用としても作られた（出典A）
- 鞘は沃懸地に飛鳥を蒔絵で表し、金具や鐔にも群鳥をあしらう（出典A）
- 刀身は備前国福岡一文字派の太刀で、茎に「一」の銘（出典A）
- 刀身と拵がほぼ同時代と考えられる数少ない例（出典A「〜と考えられる」）→ 台本も「考えられる」
- 上杉家に伝来し、上杉家から三島大社に奉納されたため上杉太刀と呼ばれる。明治時代に皇室に献納（出典A）
- 映像は刀身のみ。拵（群鳥の蒔絵・兵庫鎖）は描いていない。刃文・反りの形は出典に記載がないため推定
