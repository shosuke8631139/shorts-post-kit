# 大太刀 兼光（大太刀 銘備前国長船兼光 延文二二（四）年二月日）台本と出典

- 尺: 35.9 秒
- 作られた地域: 備前国（岡山県）。作者兼光は備前国の長船派の刀工（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 南北朝時代・延文4年（1359）（出典A）

## 伝承として扱う点（断定しない）

- 兼光は景光の子と伝え（出典A「〜と伝え」）→ 台本も「伝わる」
- 刃長が長く、身幅が広く、鋒が大きく延び、南北朝時代に見られる大太刀の典型的な作品（出典A）
- 上杉家に伝来した（出典A）
- 年紀「延文二二年」は延文四年の意（出典Aの表記「延文二二（四）年」「延文4年(1359)」）
- この刀の刃文は出典Aに記載がないため、映像の刃文はイメージ
