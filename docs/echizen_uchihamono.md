# 越前打刃物（越前打刃物（経済産業大臣指定 伝統的工芸品））台本と出典

- 尺: 39.3 秒
- 作られた地域: 福井県越前市（出典A・B）
- 現在の所蔵: （工芸品の産地紹介のため所蔵先はなし）
- 時代: 約700年の歴史（出典B・C）。伝統的工芸品の指定は昭和54年＝1979年、刃物産地として全国初（出典B）

## 伝承として扱う点（断定しない）

- 千代鶴国安が府中（越前市）に来て刀鍛冶の技術を教えたことが始まり、は出典Aで「といわれています」、来住年は「諸説あり」 → 台本は「といわれています」、年は出さない
- 越前鎌の販路を広げたのが漆掻き業者、も出典Aで「と言われています」 → 台本も伝聞のまま
- 「二枚広げ」「廻し鋼着け」の具体的な工程は公式ページに説明がない → 名前だけ紹介し、中身は説明しない
- 値段そのものは公式資料にないので扱わない
