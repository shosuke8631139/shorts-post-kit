# 亀甲貞宗（刀 無銘貞宗（名物亀甲貞宗））台本と出典

- 尺: 38.7 秒
- 作られた地域: 相模国（神奈川県）鎌倉。作者貞宗は鎌倉の刀工正宗の実子あるいは養子「といわれ」（出典A）
- 現在の所蔵: 東京国立博物館（出典A・B）
- 時代: 鎌倉～南北朝時代・14世紀（出典A・C）

## 伝承として扱う点（断定しない）

- 正宗の実子か養子かは出典A「といわれ」、出典C「とも伝えられる」→ 台本は「〜ともいわれます」
- 名前の由来＝茎の亀甲花文の彫物（出典A・B・C が一致）。彫物は大磨上の後に刻まれた（出典B）
- 彫物の面は出典Cで「指裏」。映像ではイメージとして表現（実物の紋の形・位置とは異なる）
