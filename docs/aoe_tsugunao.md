# 青江次直（短刀 銘備中国住次直作 延文三年十一月日）台本と出典

- 尺: 36.9 秒
- 作られた地域: 備中国（岡山県西部）。南北朝時代の青江派刀工・次直（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 南北朝時代・延文3年（1358）（出典A）

## 伝承として扱う点（断定しない）

- 備中国の青江派は平安時代末期に興った流派で、南北朝時代までの作品が残る（出典A）
- 次直は次吉・守次と並び南北朝時代の青江派を代表する刀工（出典A）
- 南北朝時代の作としては小振りな姿だが、匂口の締まった逆丁子刃が華やか（出典A）
- 仙台藩伊達家に伝来。寛永7年（1630）に徳川秀忠から伊達光宗が拝領（出典A）
- 刃長26.8・反り0.1（出典A）。映像の刃文は逆丁子を再現しておらず丁子風のイメージ。茎には表の銘のみを描き、裏の年紀は描いていない
