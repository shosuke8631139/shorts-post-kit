# 松本城（国宝 松本城天守（大天守・乾小天守・渡櫓・辰巳附櫓・月見櫓の五棟））台本と出典

- 尺: 49.0 秒
- 作られた地域: 長野県松本市
- 現在の所蔵: （建物のため所蔵先はなし。現地に現存）
- 時代: 天守の築造は文禄2〜3年（1593〜94）とするのが松本市の公式見解（出典A）。辰巳附櫓・月見櫓は約40年後、松平直政の時代に増築（出典D・E）

## 伝承として扱う点（断定しない）

- 築造年代は公式サイトでも「かなりの可能性を持つ推定事項」とされ、竣工を文禄4年・慶長期とする説もある。台本では「とされます」と言い、断定しない
- 「日本最古」は出典Aの表現どおり「現存する五重六階の天守では」に限って言う。城や天守全体で最古とは言わない
- 「戦国と江戸の天守・櫓がつながって残るのは日本でここだけ」は出典Aの「我が国唯一」に基づく
- 月見櫓で月を眺めた話は、出典Cでも「愛でたのでしょう」という推定。台本では「考えられています」と言う
- 国宝指定の年は出典の中で1930年・1936年の記載が分かれる（再指定は1952年）。尺の都合もあり台本では年を言わない
- 「現存12天守のひとつ」は出典Aの見出し「現存する天守12城のうち」に基づく
- 大天守の高さ（29.4mとされることが多い）は今回読んだ公式資料に記載がないため、台本では言わない

## 3Dモデルの寸法

- 大天守・乾小天守・渡櫓・辰巳附櫓・月見櫓の並びと、黒い下見板・白漆喰・石垣・お堀を再現したイメージ。各棟の幅・高さ・窓・石垣の形は推定で、実測値に基づくものではない。夜のライトアップと満月は演出。
