# 今荒波（太刀 銘一（号今荒波））台本と出典

- 尺: 36.2 秒
- 作られた地域: 記載なし。一文字派は鎌倉時代初期の備前国で興った（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 茎に「一」とのみ銘があり、片山一文字の則房によるものと伝えられる（出典A）→ 台本も「伝えられます」
- 身幅が広く腰反りがついて猪首鋒となった力強い姿（出典A）
- 刃文は高低差のある丁子刃で華やか（出典A）
- 号「今荒波」は荒波のように躍動的な刃文に由来すると考えられる（出典A）→ 台本も「考えられています」
