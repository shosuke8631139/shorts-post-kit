# 石田貞宗（脇指 無銘相州貞宗（号石田貞宗） 附黒漆小脇指）台本と出典

- 尺: 39.5 秒
- 作られた地域: 相模国（神奈川県）。作者は相州貞宗（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 南北朝時代・14世紀（出典A）

## 伝承として扱う点（断定しない）

- 相州貞宗は正宗の子とも養子とも伝えられ、通称を彦四郎という（出典A「〜と伝えられ」）→ 台本も「伝えられる」
- 号は石田三成が所持したと伝えられることから名づけられた（出典A「〜と伝えられる」）→ 台本も「伝えられる」
- 榊原家に伝来（出典A）
- 身幅が広く反りのついた姿。沸がよくついたのたれ刃で、師の正宗よりも穏やか（出典A）
- 表裏に梵字の彫物がある（出典A）が、形の資料がないため映像には描かない
