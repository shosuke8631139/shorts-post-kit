# 綾小路定利（太刀 銘定利）台本と出典

- 尺: 38.5 秒
- 作られた地域: 山城国。定利は山城国綾小路に住した刀工と伝える（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 刀剣古伝書は文永年間（1264〜75）頃の活躍としているが、現存作の作風からやや遡ると考えられる（出典A）
- 磨上げのため寸が短くなり、細身の姿（出典A）
- 定利の作の中でも地鉄が冴え、小丁子刃が整う（出典A）
