# 新藤五国光（短刀 銘国光）台本と出典

- 尺: 38.6 秒
- 作られた地域: 相模国（鎌倉）。相州国光（新藤五国光）（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 新藤五国光は鎌倉鍛冶の事実上の始祖で、正宗の師であるとされる（出典A）
- 国光の作品で最古のものは永仁元年（1293）の短刀（出典A）
- 板目肌の地鉄に地景が細かくつき、沸映りが立つ（出典A）
- 小沸のよくついた直刃の刃文（出典A）
- 寛文9年（1669）に徳川家綱から仙台藩主伊達綱村が拝領し、同家に伝わった（出典A）
- 刃長25.2・内反り（出典A）。映像では内反りは表現せず、ほぼ真っ直ぐに描いている
