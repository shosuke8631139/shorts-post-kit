# 厚藤四郎（短刀 銘吉光（名物厚藤四郎））台本と出典

- 尺: 38.9 秒
- 作られた地域: 京都・粟田口。作者吉光は鎌倉時代の京都・粟田口派の刀工（出典A・B）
- 現在の所蔵: 東京国立博物館（出典A・C）
- 時代: 鎌倉時代・13世紀（出典A・B）

## 伝承として扱う点（断定しない）

- 号の由来＝刀身（重ね）が極端に厚いこと（出典A・B が一致）
- 伝来のうち一柳直末・黒田如水・豊臣秀次・秀吉・毛利秀元を経て徳川家綱へ、は出典Aで「献上されたという」→ 台本は「伝わったといいます」。足利将軍家・徳川将軍家への伝来は出典B
- 読みは出典A・B（東京国立博物館）の「あつしとうしろう」を採用（出典Cの文化庁DB由来の表記は「あつとうしろう」）
