# 切刃貞宗（刀 無銘貞宗（名物切刃貞宗））台本と出典

- 尺: 38.9 秒
- 作られた地域: 相模国（神奈川県）。作者貞宗は相模国の刀工（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 南北朝時代・14世紀（出典A・B）

## 伝承として扱う点（断定しない）

- 号の由来＝指表が鎬造、指裏が切刃造であること（出典A）
- 貞宗は正宗の実子とも養子とも「伝えられる」（出典A）→ 台本も「といわれます」
- 豊臣秀吉・前田利家などへ移り、元禄10年（1697）に紀州徳川家から将軍家へ献上（出典A）
