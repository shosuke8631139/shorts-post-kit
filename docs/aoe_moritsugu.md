# 青江守次（太刀 銘備中国住守次作 延文二年十二月日）台本と出典

- 尺: 38.4 秒
- 作られた地域: 備中国（岡山県西部）。南北朝時代の青江派刀工・守次（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 南北朝時代・延文2年（1357）（出典A）

## 伝承として扱う点（断定しない）

- 刃長が長く、身幅が広く、鋒が延びた太刀で、製作当初の姿をよく留めている（出典A）
- 小板目肌がよく約み棒映りが立つ地鉄、匂口の締まった直刃（出典A）
- 鎌倉時代中期の青江派にも同名の刀工がいるが、この守次は南北朝時代の青江派刀工（出典A）
- 刃長86.0・反り3.2（出典A。単位の記載はないが cm として扱う）
- 映像の茎には表の銘のみを描き、裏の年紀は描いていない
