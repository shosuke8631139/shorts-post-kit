# 豆板銀（江戸時代の銀貨・豆板銀（重さで取引する秤量貨幣））台本と出典

- 尺: 72.6 秒
- 作られた地域: （貨幣の解説のため産地はなし）
- 現在の所蔵: （特定の実物を扱わないため所蔵先はなし）
- 時代: 江戸時代。1601年に慶長金銀を発行（出典C）、図録に「慶長丁銀・豆板銀」（出典E36）。18世紀後半に計数銀貨が出ると秤量銀貨はほとんど流通しなくなった（出典E42）

## 伝承として扱う点（断定しない）

- 豆板銀の形・大きさ・刻印の図柄、発行開始年、品位は、確認できた公式資料に記載がないため台本では言わない。映像の形（いびつな粒）と刻印（寳の文字）はイメージ
- 「丁銀の重さの調整に豆板銀を使った」はよく言われるが、公式資料に記載がないため言わない
- 天秤と分銅は出典E41の「丁銀は重さをはかって使う貨幣であり、両替には天秤と分銅が不可欠」による。豆板銀も同じ秤量貨幣（出典C）
- 金1両＝銀60匁は1700年以降の公定相場（出典B・C）。江戸初期は銀50匁（出典B）。実際の相場は毎日変動した（出典B）
- 「1匁＝約1350円」は出典Bの仮の計算（18世紀の米価で1両＝約81,000円）を60で割ったこちらの計算

## 3Dモデルの寸法

- 少しいびつな丸い銀の粒（刻印は寳の文字）を想定したイメージ。形・大きさ・刻印は推定で、特定の豆板銀や出典の記載に基づくものではない。画面上は大きさをそろえるため拡大して表示。
