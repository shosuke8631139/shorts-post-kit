# 城和泉守正宗（刀 金象嵌銘城和泉守所持 正宗磨上本阿（花押））台本と出典

- 尺: 38.6 秒
- 作られた地域: 相模国（神奈川県）。作者正宗は相模国の刀工、五郎入道と名乗り鎌倉時代末期に活躍（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・14世紀（出典A）

## 伝承として扱う点（断定しない）

- 本阿弥光徳が正宗作と鑑定し、慶長14年（1609）に埋忠寿斎が研ぎ上げて金象嵌の銘をほどこした「と記録にある」（出典A）→ 台本も「記録があります」
- 銘の城和泉守＝武田信玄の家臣で、武田氏滅亡後に徳川家康に仕えた城昌茂（出典A）
- のち弘前藩主の津軽家に伝わった（出典A）
- 細身で鎌倉時代の太刀姿をしのばせる。地鉄や変化に富む刃文は正宗作刀の中でも逸品（出典A）
