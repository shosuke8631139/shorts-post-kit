# 笹貫（太刀 銘波平行安（号 笹貫））台本と出典

- 尺: 39.5 秒
- 作られた地域: 作者の波平行安は薩摩国の波平（現在の鹿児島市の南郊）に住した刀工（出典A・Bの記述）。この一振りを打った場所そのものは資料に明記なし
- 現在の所蔵: 京都国立博物館（ColBase「所蔵者」欄）
- 時代: 鎌倉時代 前期・13世紀

## 伝承として扱う点（断定しない）

- 「笹貫」の号の由来は公式解説に書かれていない → 台本では由来を語らない
- 行安あるいは始祖の正国が大和から出たという話は「所伝」と記載 → 台本では扱わない
