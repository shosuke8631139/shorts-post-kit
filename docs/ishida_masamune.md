# 石田正宗（刀 無銘正宗（名物石田正宗））台本と出典

- 尺: 39.1 秒
- 作られた地域: 相模国鎌倉（神奈川県）。作者正宗は14世紀に鎌倉で活躍した刀工（出典B）
- 現在の所蔵: 東京国立博物館（出典A・C）
- 時代: 鎌倉時代・14世紀（出典A・B）

## 伝承として扱う点（断定しない）

- 号の由来＝石田三成が持っていた刀（出典B）
- 毛利若狭守→宇喜多秀家→石田三成、三成から結城秀康へ御礼として贈られた話は『享保名物帳』による（出典A「〜という」「〜とされている」）→ 台本も「〜とされます」
- 切込は「敵と切りあったときにできたもの」（出典B）。『享保名物帳』の「石田切込」（出典A）。いつ誰との戦いかは書かれていないので言わない
