# 観世正宗（刀 無銘正宗（名物観世正宗））台本と出典

- 尺: 39.1 秒
- 作られた地域: 相模国（神奈川県）。作者正宗は鎌倉時代末期の相模国の刀工（出典A・B）
- 現在の所蔵: 東京国立博物館（出典A・C）
- 時代: 鎌倉時代・14世紀（出典A・B）

## 伝承として扱う点（断定しない）

- 号の由来＝能楽の観世家が所持していた／伝わったこと（出典A・B）
- 家康が観世家から召し上げ秀忠に与え、家臣との間で拝領と献上を繰り返した話は『享保名物帳』による（出典A「〜という」）→ 台本は出典Bの「観世家から徳川家康に献じられ」だけを使う
- 正宗の師（新藤五国光）・相州伝の完成は出典B（東京国立博物館の解説）
- 茎に梵字などの彫物が残る（出典A）が、形の資料がないので映像には描かない → 台本でも触れない
