# 岡田切（太刀 銘吉房（号岡田切））台本と出典

- 尺: 34.3 秒
- 作られた地域: 備前国（岡山県東南部）。作者吉房は福岡一文字派の刀工（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 天正12年（1584）小牧長久手の戦のとき、織田信雄がこの刀で家臣の岡田助三郎重孝を斬ったことから「岡田切」の号で知られる（出典A）
- 反りがやや高く身幅が広い。吉房の作刀の中で最も華やかな作風の代表作（出典A）
- 吉房は助真・則房とともに鎌倉時代中期に活躍（出典A）
