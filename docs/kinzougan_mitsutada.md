# 金象嵌銘光忠（刀 金象嵌銘光忠 本阿（花押））台本と出典

- 尺: 38.8 秒
- 作られた地域: 備前国（岡山県）。長船派の刀工・光忠（出典A）
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 長船派は刀剣古伝書では近忠が始祖と言われるが現存作がなく、子と伝える光忠が一派の事実上の祖と考えられている（出典A「〜と考えられている」）→ 台本も「考えられている」
- 光忠は鎌倉時代中期の刀工で、映りの立った精緻な地鉄に、丁子刃に蛙子丁子刃を交えた刃文が特色（出典A）
- 本阿弥家の13代・光忠（こうちゅう）が、光忠（みつただ）の作と極めたもの（出典A）。台本では同名の混乱を避けて「本阿弥家の13代」とした
- 磨上げられて寸法が短くなっているが、身幅が広く猪首鋒の豪壮な姿（出典A）
- 刃文は丁子刃に大きな蛙子丁子刃や袋丁子刃、飛焼が交じり華やか（出典A）
- 徳川将軍家に伝来（出典A）
- 映像の茎には金象嵌の「光忠」のみを描き、「本阿（花押）」は描いていない
