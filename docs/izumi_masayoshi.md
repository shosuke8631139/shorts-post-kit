# 正良（脇差 銘 薩摩國出水藤原正良）台本と出典

- 尺: 36.3 秒
- 作られた地域: 銘に「薩摩國出水」（刀工の名乗り）。出水は現在の鹿児島県出水市と同じ地名（範囲の一致までは主張しない）
