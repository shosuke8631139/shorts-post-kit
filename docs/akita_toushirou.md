# 秋田藤四郎（短刀 銘吉光（名物秋田藤四郎））台本と出典

- 尺: 38.9 秒
- 作られた地域: 山城国（京都府）。吉光は山城国粟田口派を代表する工人（出典A）
- 現在の所蔵: 京都国立博物館（出典A）
- 時代: 鎌倉時代・13世紀（出典A）

## 伝承として扱う点（断定しない）

- 吉光の現存作例はほとんどが短刀（出典A）
- 本品は吉光の作品のうち最も小ぶりで繊細なもの（出典A）
- やや内反り気味で振袖風の茎を備え、鎌倉時代中期の時代性を伝える（出典A）
- 刃文は直刃を基調に小足が入り、小互の目を交えて小乱れとなるなど粟田口派の作風がうかがえる（出典A）
- 秋田城介の所持であったため「秋田藤四郎」と呼ばれる御家名物。豊前国小倉藩主小笠原家に伝来（出典A）
