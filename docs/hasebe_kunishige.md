# 長谷部国重（短刀 銘 長谷部国重）台本と出典

- 尺: 37.7 秒
- 作られた地域: 京都。作者国重は南北朝時代の京都で活動した長谷部派の刀工（出典A）
- 現在の所蔵: 京都国立博物館（出典A）
- 時代: 南北朝時代・14世紀（出典A）

## 伝承として扱う点（断定しない）

- 刃長が一尺を超える大振りの短刀は「寸延短刀」と呼ばれる（出典A）
- 長谷部派は大和鍛冶を祖に持ち、鎌倉時代後期に鎌倉に移住したのち、新藤五国光ら相州鍛冶の影響を受けたと考えられている（出典A「〜と考えられている」）→ 台本も「考えられています」
- 国重は同流派の実質的な初代。在銘のものは短刀に偏重し数も少なく、本品は国重在銘の貴重な作例（出典A）
- わずかに反りのついた刀身、身幅が広く重ねが薄い点に南北朝時代の特徴（出典A）
- のたれを主体とした錵づく刃文。映像の刃文はイメージで、のたれは再現していない
