# 獅子王（太刀 無銘（号獅子王） 黒漆太刀）台本と出典

- 尺: 35.0 秒
- 作られた地域: 大和国（奈良県）で制作されたものと「考えられる」（出典A）→ 台本・情報カードも「考えられる」
- 現在の所蔵: 東京国立博物館（出典A）
- 時代: 刀身は平安時代・12世紀（出典A）

## 伝承として扱う点（断定しない）

- 諸説あるが、源頼政が鵺退治の功績によって天皇より賜った太刀「とされている」（出典A）→ 台本も「諸説ありますが〜とされます」
- のちに土岐家に伝わり、明治15年（1882）に土岐頼近から東久世通禧を通じて明治天皇に献上（出典A）
- 細身で腰から反りが強く、先が伏しごころの平安時代後期の古雅な姿。匂口の締まった直刃（出典A）
- 黒漆太刀の拵（鎌倉時代）は映像に描かない
