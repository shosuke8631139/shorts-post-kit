# 三日月宗近（太刀 銘三条（名物 三日月宗近））台本と出典

- 尺: 36.2 秒
- 作られた地域: 京都・三条（作者がそこに住んだと伝わる。伝承）
- 現在の所蔵: 東京国立博物館（所有者：独立行政法人国立文化財機構）
- 時代: 平安時代（10〜12世紀）

## 伝承として扱う点（断定しない）

- 作者宗近が京都の三条に住んだこと（「伝えられる」と記載）
- 銘「三条」の作者を宗近と同一人物とすること（「古来宗近同人と伝え」と記載）
